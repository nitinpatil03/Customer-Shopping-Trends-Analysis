# 📊 Customer Shopping Behavior Analysis | Python, SQL & Power BI

## 📌 Project Overview
This project analyzes customer shopping behavior using Python, SQL, and Power BI to identify purchasing patterns, customer preferences, and sales trends. The goal is to generate actionable business insights that help businesses make data-driven decisions.

## ❗ Problem Statement
Businesses often struggle to understand customer purchasing patterns, product preferences, and factors influencing buying decisions. This project aims to analyze customer shopping data to identify key trends, understand customer behavior, and provide insights that can help improve sales, customer satisfaction, and retention.

## 🎯 Business Objectives
- Analyze customer purchasing behavior and preferences.
- Identify popular product categories and sales trends.
- Understand the impact of discounts on purchasing decisions.
- Compare subscribed and non-subscribed customer behavior.
- Identify customer segments and purchasing patterns.
- Provide actionable business recommendations.

## 🔄 Project Workflow

1. **Data Loading:** Imported and explored the customer shopping dataset using Python.
2. **Data Cleaning:** Handled missing values, duplicates, and data inconsistencies.
3. **Exploratory Data Analysis:** Analyzed customer behavior and purchasing trends.
4. **SQL Analysis:** Used SQL queries to answer important business questions.
5. **Dashboard Development:** Created an interactive Power BI dashboard to visualize key insights.

## 📈 Key Insights
- Identified popular product categories and customer preferences.
- Analyzed purchasing patterns across different customer segments.
- Evaluated the impact of discounts on customer purchases.
- Compared subscription and non-subscription purchasing behavior.
- Identified trends that can support better business decisions.

## 💡 Business Recommendations
- Develop targeted marketing strategies for different customer segments.
- Improve customer retention through loyalty and subscription programs.
- Optimize discount and promotional strategies.
- Focus on popular product categories to improve sales performance.

## 📂 Project Files

- `Customer_Shopping_Behavior_Analysis.ipynb` – Python analysis and data cleaning.
- `customer_behavior_sql_queries.sql` – SQL queries for business analysis.

- `customer_shopping_behavior.csv` – Dataset used for analysis.

## 🚀 How to Run the Project

**1. Clone the repository**
```bash
git clone <https://github.com/nitinpatil03/Customer-Shopping-Trends-Analysis>
```

**2. Install required libraries**
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**3. Run the Jupyter Notebook**
```bash
jupyter notebook
```

**4. Execute SQL queries** using your preferred SQL database.

**5. Open the `.pbix` file** in Power BI Desktop to explore the dashboard.
